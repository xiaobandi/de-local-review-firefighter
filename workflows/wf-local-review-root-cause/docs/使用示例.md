# 使用示例

技能：**根因归类**（`wf-local-review-root-cause`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/sentiment_tag.py --file examples/input/reviews.txt
```

**真实输出**：

```console
 [P2-归因分析] 1001 正面 | 物流 | 东西很好用，物流也快，会回购
⚠[P0-立即处理] 1002 负面 | 质量 | 垃圾质量！退货退款，再不处理我就12315投诉你们
 [P1-当日处理] 1003 负面 | 物流 | 物流有点慢，但东西还行
 [P1-当日处理] 1004 负面 | 服务 | 客服态度太差了，问三遍不回
 [P1-当日处理] 1005 负面 | 质量 | 呵呵，真是"太好"了，用两天就坏

汇总：5 条 | 负面 4 | 需升级 1
```

> 规则基线逐条打标；注意 r1005 反讽句被误判为正面——这正是基线必错项

> **注意**：**反讽是规则基线的必错项**（看 r1005）。基线负责不漏，模型负责复核，不可省。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/sentiment_tag.py --file /path/to/your-data/reviews.txt
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/sentiment_tag.py --file examples/input/reviews.txt || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
